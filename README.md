# SillyTavern 快捷工具栏

_一个功能丰富的 SillyTavern 输入辅助插件，提供快捷输入、导航跳转、消息管理、工具栏定制等实用功能。_

## 功能一览

### 文本编辑

- **撤回 / 重做**：支持多步撤回和重做，最多保留 50 步历史记录
- **选中模式**：移动端文本选择辅助，点击锚定起点后再点击另一位置即可选中两点之间的文本
- **成对符号插入**：一键插入 `**`、`""`、`()`等成对符号，自动将光标定位在中间；如果已选中文本，会自动用符号包裹
- **快速换行**：自动移动到当前行末尾并插入换行符
- **插入标记**：快速插入 `{{user}}` 和 `{{char}}` 宏
- **查找替换**：在输入框或正在编辑中的消息里查找和替换文本，支持 Enter / Shift+Enter 跳转、Esc 关闭

- **启动显示**：未开启固定展开时，刷新后的脚本聚焦不会自动展开工具栏；真实操作后恢复正常显示，兼容外部编辑器和 iframe。

- **CodeMirror 查找兼容**：查找替换可识别新版 CodeMirror 6（包括 ST-BaiBai-Tools），并修正上一处/下一处主动聚焦时匹配索引被清空的问题；保留原有滚动、替换和撤回/重做逻辑。

### 编辑器 Token 计数

- **原生界面只补预设正文**：在 Prompt Manager 编辑页的「提示词」标题后显示 `(Tokens: 数字)`。世界书、角色卡原有的计数不改动、不重复添加，也不在条目名称后加计数。
- **指定悬浮窗**：角色描述 / 性格 / 场景 / 开场白 / 对话示例 / 角色提示词、用户设定、世界书正文、预设条目及系统提示词等正文窗口，在标题下方与保存状态同一行显示小字计数，不占用标题空间。CSS、聊天输入、角色名称 / 标签 / 创作者备注和普通插件配置框不显示。
- 直接使用酒馆当前分词器统计**本窗口原文**，停下输入约 500ms 后更新；模型 / 分词器变化后重算。每个窗口各算自己的草稿，不读取当前选中的另一条目，也不会触发保存。为避免串角色上下文，不展开宏；数字不是完整请求的最终 token 用量。
- 样式沿用原生 `small` 小字与 `(Tokens: n)` 形式，不加背景、边框、徽章或阴影。计数异常显示 `—`，不会拿假数字代替，也不影响继续编辑。

### 悬浮编辑窗

- 在放大按钮左侧增加 **悬浮编辑** 入口，支持自定义 CSS、角色描述 / 性格 / 场景 / 主开场白、世界书条目、预设条目及已适配插件的文本框；原放大按钮保留。
- **同步方式**：已保存角色的描述、性格、场景和主开场白使用独立草稿，停下输入后自动保存；已有预设条目使用独立草稿，关闭时自动保存，也可手动保存（见下文）；其他字段仍双向实时同步，沿用原有保存机制，支持已识别的新旧 CodeMirror 6 编辑器。
- 拖动标题栏移动，右下角调整大小；图钉固定位置和尺寸，折叠按钮收起正文；记住上次的位置和展开尺寸，这些布局信息可跨刷新保留，但未保存的草稿文本不会随之恢复。
- 原生风格 FA 入口紧挨放大图标左侧；切换酒馆主题时，已打开窗口的配色和编辑区字体同步切换，无需重新打开。
- 编辑区底部保留紧凑单行图标：左侧为 **撤销 / 重做**，右侧为 **查找** 和仅自定义 CSS 显示的 **取色器**，与缩放图标水平对齐；按钮无底块，悬停仅点亮图标，280px 小窗与手机也不换行，折叠时隐藏。查找复用插件共享查找栏，不再内置另一套搜索 / 替换界面；撤销 / 重做走统一入口，**每个窗口保留独立会话历史**。
- **总计最多 3 个悬浮编辑窗**，包含角色字段草稿、预设条目草稿和其他字段窗口。独立字段草稿不因切换角色锁定；未适配的其他角色字段、世界书条目、自定义 CSS、插件输入框，以及尚未保存的新建角色表单仍使用源输入框实时同步模式：绑定上下文变化时，旧窗口锁定并保留内容供复制，不会写入新对象。
- **变更历史**：连续编辑停下约 **3 秒** 后合并记录，持续输入每 30 秒保留一个检查点；打开历史或执行撤销 / 恢复等操作前会先将待记录内容存入历史。与原有撤销 / 重做栈分离，不改变其行为。预览以绿色标出新增、红色删除线显示删除，支持 **上一处 / 下一处变动** 定位；「回到此状态」只恢复真实快照，不会把删除标记写入正文。角色字段草稿的撤销 / 重做、历史恢复及「恢复」也会触发自动保存；预设草稿的这些操作可手动保存，也会在关闭悬浮窗时自动保存。
- 实时同步模式下，**关闭不撤销已同步的修改**，而「恢复」会在确认后写回打开窗口时的内容。自定义 CSS 若把界面改坏，可按 **Ctrl/⌘ + Alt + Backspace** 请求恢复；**Ctrl/⌘ + Alt + Esc** 关闭窗口，角色字段草稿会先等待待处理的自动保存完成，成功后关闭；失败或结果不确定时保留文本，并在丢弃前确认。
- 默认启用，可在插件设置 → 更多设置中关闭「悬浮编辑窗」。详细操作见插件设置中的「帮助」。

#### 多角色字段：独立草稿与自动保存

- **适用范围**：已保存角色的原生描述（`description_textarea`）、性格（`personality_textarea`）、场景（`scenario_pole`）和主开场白（`firstmessage_textarea`）使用专用内置适配器，按 **角色 avatar + 字段** 绑定独立草稿，标题标明角色和字段。切换 A/B 后两份草稿仍可编辑；同一角色的不同字段也可分别开窗，再次打开同一角色的同一字段则聚焦已有草稿。
- **主开场白范围**：保存的是角色卡的 `first_mes`，不修改已有聊天消息，也不修改备用开场白列表。
- **自动保存**：停止输入约 **700ms** 后，自动写入草稿绑定的角色及字段，不覆盖其他字段或当前选中的其他角色。窗口底部没有 **保存 / 重新加载** 按钮，也没有专用 **Ctrl/Cmd+S** 保存快捷键；状态栏提示加载、待保存、保存中、已保存以及错误 / 冲突状态。
- **同角色保存排队**：同一 avatar 的保存请求按顺序串行执行，包括不同字段的保存；不会因该角色正在保存而以「忙碌」拒绝后续保存。
- **失败与重试**：临时性保存失败会进行有上限的自动重试；永久性服务器错误不会无限重试，达到重试上限后也不会持续请求。加载 / 保存失败或保存结果无法确认时保留当前文本并提示，不把不确定结果视为已保存。
- **冲突处理**：保存前若发现服务器同一字段与草稿基线不同，窗口会暂停自动同步并锁定，保留可复制文本，不强制覆盖。先复制需要保留的内容，再关闭锁定窗口并重新打开该角色字段，基于服务器最新记录继续编辑。此检查不提供跨标签页或跨浏览器的原子锁保证。
- **关闭窗口**：正常关闭（包括关闭快捷键）会先等待待处理的自动保存完成，成功后再关闭；保存失败、结果不确定或冲突尚未解决时保留文本，并在丢弃前请求确认。
- **离开或刷新页面**：存在未保存或保存结果尚未确认的修改时，会请求浏览器显示离页提示。草稿不跨刷新持久化，刷新后不能恢复未保存草稿；窗口位置 / 尺寸的记忆不等于草稿存储。

#### 预设条目：独立草稿与关闭时自动保存

- Prompt Manager 的**已有文本条目**按「预设名 + 条目 identifier」绑定独立草稿。关闭或保存原生编辑面板、打开条目 B，都不会清空或改写条目 A 的悬浮窗；再次打开 A 会聚焦原草稿。与其他窗口共用最多 3 个窗口的上限。
- **多条目并排**：A 的窗口保留时，点击 B 的悬浮入口会新增第二个窗口；再次打开 A 只聚焦已有窗口。不因切换条目自动保存、刷新或替换 A；达到 3 个窗口上限也不挤掉旧窗。仅切换原生条目面板不会自动打开新悬浮窗。
- 在悬浮窗里编辑不会立即回写那个被酒馆反复复用的原框。关闭悬浮窗时会先自动保存绑定条目的正文，成功后直接关闭，不再弹出常规确认。底部保留**纯 FA 保存图标**及 **Ctrl/⌘+S**，用于保存但继续编辑；不会修改名称、角色、排序等设置，也不关闭原面板。
- **保存条目不等于保存整份命名预设**：确认条目编辑完成后，仍需使用酒馆的「保存预设」按钮，才能保证重新切换/加载该命名预设时仍有这些修改。QuickBar 不会替你覆盖整份预设。
- 切到另一份预设后，旧草稿仍可继续编辑；需切回原预设再保存。条目被删除、原框同时被修改、条目正文发生冲突或保存失败时，会拒绝不安全的写入并保留草稿，不覆盖其他条目。尚未保存的新条目需先在原面板保存一次。
- **不会因原面板关闭或切换条目而自动丢弃草稿**；关闭悬浮窗 / 停用功能时会等待待保存内容完成；只有保存失败、结果未确认或发生冲突时，才询问是否放弃并关闭，取消则保留草稿。刷新或离开时也有未保存提示，但草稿不跨刷新存储，请先保存或复制备份。
- 其他实时同步窗口没有单独保存步骤：已同步或未修改的内容，即使因原框关闭 / 切换而锁定，关闭或刷新也不再弹出未保存确认；只有尚未同步出去的本地修改才会提醒保留内容。关闭时会先尝试写回尚未结束的组字输入；角色字段仍按原有规则自动保存。

### 导航功能

- **跳转聊天顶部**：始终定位到聊天区当前已加载的第一条可见消息，不重新加载聊天或调整历史加载条数；自动兼容已识别的近顶历史加载逻辑
- **跳转聊天底部**：光标在文本编辑框（含悬浮编辑窗）时回到框内末尾，否则跳到聊天底部，不改动文本和选区
- **跳转 AI 消息顶部**：滚动到最新一条 AI 回复的顶部；光标在编辑框内（发送框除外）时回到框内开头
- **上 / 下一条 AI 消息**：在 AI 消息之间快速跳转
- **跳转指定楼层**：输入楼层号直接跳转
- **翻页模式**：开启后导航按钮变为翻页操作；移动端点击聊天区域上半部分向上翻页、下半部分向下翻页；支持音量键翻页（需安装 Key Mapper），双击音量上键跳到最新 AI 消息顶部，双击音量下键跳到聊天底部
- **自动滚动**：以设定速度自动向下滚动，适合阅读长文；用户手动滚动时暂停，2 秒后恢复

### 消息操作

- **删除最后消息**：快速删除最后一条消息（支持确认弹窗）
- **删除当前备选**：删除最后一条消息的当前备选回复
- **继续回复**：让 AI 继续生成当前回复
- **重新生成**：重新生成最后一条 AI 回复
- **QR 助手面板**：一键打开 Quick Reply 助手面板（需安装 QR 助手插件）[QR 助手](https://github.com/uhhhh15/QR.git)

### 消息隐藏管理

管理聊天消息在 AI 提示词中的可见性，隐藏的消息不会发送给 AI：

- 隐藏 / 显示指定楼层或范围
- 只保留最近 N 条消息可见
- 一键隐藏全部 / 显示全部
- 实时显示当前隐藏状态

### 自定义内容

- 添加任意自定义插入内容，点击按钮即可插入到输入框
- 支持短符号、宏标签、常用短语、整段模板文本（多行段落）
- 自定义按钮显示文字或 Font Awesome 图标（长段落建议配简短显示或图标）
- 可设置插入后的光标位置（开头、中间、结尾或自定义偏移，方便定位到需要补充的位置）

### 按钮分组

- 将多个按钮收纳进文件夹，工具栏只显示一个折叠按钮
- 点击文件夹按钮展开下拉菜单
- 支持自定义文件夹名称和图标
- 按钮可在文件夹之间自由拖拽移动
- 文件夹内按钮支持拖拽排序
- 文件夹内所有按钮被禁用或被悬浮面板占用时，文件夹按钮自动隐藏

### 工具栏定制

- 勾选控制每个按钮的显示 / 隐藏
- 拖拽调整按钮和文件夹的显示顺序
- 支持固定展开模式（无需聚焦输入框）
- **双栏模式**：工具栏分为符号输入栏和功能按钮栏，两行各自独立横向滚动，可调整上下顺序

### 外部入口（实验性）

- 展开「按钮管理」后，内部有「魔法棒入口」和「扩展面板入口」两个独立折叠区域，沿用角色专属区域的样式；不是额外的工具栏文件夹。
- 在对应区域点击「扫描入口」，勾选后选择「仅隐藏原入口」或「加入所选」。只保存选中的项目，未选项不会常驻管理列表，也不会后台自动加入。
- **仅隐藏原入口**：只保存独立隐藏规则，不生成快捷按钮，不参与快捷键或布局；可在原分类单项或全部恢复。
- 魔法棒快捷入口转发点击到原按钮；扩展面板快捷入口打开扩展抽屉、展开对应的顶层插件面板并定位。不会复制、移动原入口或整个面板。
- 默认使用原入口的 FA 图标；没有图标时使用通用图标。已加入的按钮可点击图标选择按钮更换 FA 图标，选择「无图标」恢复默认。
- 已加入的入口支持现有的启用开关、快捷键、区域内排序、文件夹、角色专属区域和悬浮面板选择。移除会清理该快捷入口的布局与快捷键，不影响原插件。
- **快捷入口隐藏**：已加入快捷入口的隐藏偏好可在「更多设置」统一切换，或通过入口行的眼睛按钮单独调整；初始默认关闭，仅快捷布局实际可访问时才隐藏原入口，不影响独立隐藏规则。
- 已加入的入口在来源暂时未加载、被来源隐藏或禁用时提示不可用并保留配置；点击时重新定位原入口，支持插件重建 DOM。不处理额外顶栏、iframe / 沙盒内部、面板里的子操作或复杂交互。没有稳定标识且名称重复的入口不会列出。

### 悬浮面板

- **悬浮球模式**：可拖拽的悬浮球，点击展开功能面板
- **固定面板模式**：常驻显示的可拖拽功能面板
- 自定义悬浮球外观（图片 / GIF、大小、圆形 / 方形、透明背景、透明度）
- **悬浮球大小**：圆形 / 方形均支持 24–80px，默认 48px；滑块和数字输入同步调整
- 支持展开态和收起态使用不同图片
- 面板方向可选竖向或横向
- 面板按钮支持拖拽排序和自定义大小
- **自动隐藏**：点击聊天区域显示 / 隐藏，点击其他区域自动收起
- **键盘自适应**：移动端键盘弹起时，面板自动避开酒馆顶栏并在必要时支持滚动
- 放入悬浮面板的按钮不会在主工具栏重复显示

### 辅助功能

- **非流自动跳转**：非流式模式下 AI 生成完毕自动滚动到该条消息顶部
- **续写时锁定滚动**：使用「继续回复」续写期间锁定聊天滚动位置，方便边看边续写；普通生成、重新生成、切换备选等其他场景不受影响；手动滚动可解除锁定
- **删除确认**：删除类操作可开启弹窗确认防止误操作
- **自动滚动速度**：可调节自动滚动的速度
- **美化指南**：内置提示词生成器，复制给 AI 即可生成匹配当前主题的工具栏美化 CSS

2. 点击「安装扩展」，输入以下地址：

## 使用说明

### 添加外部入口

1. 确认原插件或脚本已加载，打开 **扩展 → 快捷工具栏 → 按钮管理**。
2. 展开「魔法棒入口」或「扩展面板入口」，点击「扫描入口」。
3. 勾选需要的项目，选择「仅隐藏原入口」或「加入所选」。已加入快捷入口的项目会标记「已添加」；未选项目不会保存，也不会在后台自动加入。
4. 加入快捷入口后，从工具栏点击新按钮：魔法棒入口调用原功能，扩展面板入口打开扩展抽屉、展开对应顶层面板并定位。扫描本身不会打开面板或执行功能。

仅扫描标准魔法棒菜单（`#extensionsMenu`）中的按钮，以及扩展设置（`#extensions_settings` / `#extensions_settings2`）下的顶层原生折叠面板。不隐藏核心酒馆顶栏、发送按钮，也不扫描额外顶栏、iframe / 沙盒内部或面板内的子操作。没有稳定标识且名称重复的入口不会列出。未找到时先确认来源已加载，再重新扫描。

### 仅隐藏原入口

在扫描结果中勾选尚未加入快捷入口的项目，点击 **仅隐藏原入口**。仅保存独立隐藏规则，不生成快捷按钮，不进入文件夹、角色专属区域或悬浮面板的按钮选择器，也不写入快捷键、排序或布局。

- **查看与恢复**：分类下即使只有仅隐藏记录，也会显示小字「仅隐藏原入口 · n」和「全部恢复」。每条记录仅显示原 FA 图标、名称和眼睛恢复按钮；点击眼睛即删除该规则并恢复原入口。「全部恢复」只作用于当前分类的仅隐藏记录，不影响已加入快捷入口的隐藏偏好。
- **转换为快捷入口**：已有仅隐藏项仍可在扫描中勾选，点击「加入所选」即删除独立隐藏规则并转换为快捷入口，随后遵从快捷入口隐藏策略和最近一次统一隐藏默认。已加入的快捷入口不会重复创建仅隐藏规则，其原入口显示仍由原入口行的眼睛按钮管理。
- **启用与保留**：QuickBar 启用时，独立隐藏不要求存在可达的快捷布局；关闭 QuickBar 会恢复来源，重新启用后按保留规则隐藏。规则随设置保存，来源暂时不存在时仍保留，来源重建后可继续应用。
- **与统一设置分离**：「更多设置 → 快捷入口可用时隐藏原入口」只批量影响已加入快捷入口，对独立隐藏不生效。恢复仅撤销 QuickBar 的隐藏，不改变来源自身的隐藏或禁用状态。

### 调整图标、快捷键与布局

以下操作仅适用于已加入的快捷入口，独立隐藏记录不参与。

- **启用与快捷键**：通过入口行的勾选框和快捷键输入框设置，操作与内置按钮一致。
- **更换图标**：点击入口行的图标选择按钮，选择 FA 图标；选择「无图标」恢复原入口图标，原入口没有图标时使用通用图标。
- **排序与收纳**：拖动行首手柄可在同类入口内排序。已加入快捷入口会出现在文件夹、角色专属区域和悬浮面板的按钮选择器中，可从对应区域添加、排序。文件夹或角色区域已收纳的入口在对应区域管理，原分类仍保留入口总数提示。
- **移除**：点击入口行的垃圾桶，删除该 QuickBar 快捷入口，并清理它在文件夹、角色区域、悬浮方案中的布局和快捷键，不卸载原插件或删除原按钮。
- **来源暂不可用**：原入口未加载、被原插件隐藏或禁用时，点击会提示不可用并保留配置。来源恢复后再次点击会重新定位原节点，无需重复添加；尚未收录的入口仍需手动扫描。

### 隐藏原入口

在 **更多设置 → 快捷入口可用时隐藏原入口** 统一开启或关闭所有已加入快捷入口的隐藏偏好，初始默认关闭；不修改独立隐藏规则。新加入的快捷入口（包括由仅隐藏项转换的入口）沿用最后一次统一设置；已有单项偏好不会在升级时被覆盖，来源脚本的默认提示也不会绕过这一策略。

每个已加入快捷入口行的 **眼睛按钮** 仍可独立调整；部分开启、部分关闭时，统一开关显示半选。统一切换只修改这些快捷入口的隐藏偏好，不改变启用状态、排序、文件夹或悬浮布局，也不自动收录新入口。

对于已加入的快捷入口，仅在 QuickBar 有实际可访问的快捷布局时隐藏原入口：

- 已显示且可用的工具栏按钮；
- 可打开的文件夹，或当前角色的专属入口；
- 可用的固定悬浮面板，或能展开面板的悬浮球。

上述快捷入口仅保存了配置或快捷键、按钮被禁用、文件夹不可达或 QuickBar 关闭时，不隐藏原入口。移除快捷入口、关闭其隐藏偏好或失去可用布局时恢复原入口；关闭悬浮面板后若按钮回到可用工具栏，仍保持隐藏。独立隐藏不受快捷布局可达性限制，见「仅隐藏原入口」。

**使用时显示扩展标题**：从 QuickBar 快捷入口打开扩展面板时，默认临时显示对应的原生标题头，保留标题上的按钮与折叠功能；收起该面板或关闭扩展页后，重新按原隐藏偏好处理。再次打开扩展页不会自动显示，需要从 QuickBar 再次进入。无需额外设置，不影响魔法棒入口或「仅隐藏原入口」规则，也不改变已保存的隐藏偏好。

原节点和事件不删除、不移动。扫描和点击转发只忽略 QuickBar 自己的显示遮罩，不绕过原插件的隐藏或禁用状态。第三方脚本可能有额外点击限制，建议先保留原入口，确认兼容后再开启快捷入口隐藏。表情包管理器使用标准魔法棒入口扫描接入，位置、文件夹与悬浮布局由 QuickBar 管理。

### 聊天回顶

「跳转聊天顶部」始终定位到当前已加载的第一条可见消息，不重新加载聊天，也不调整历史加载条数。对已识别的近顶自动加载逻辑，插件仅在本次导航期间临时隔离定位，完成后清理，不修改其他插件的代码、设置或加载器。

无需额外开启选项；普通原生聊天沿用正常滚动。若需查看更早的历史，仍使用酒馆或原插件的加载方式；正常滚轮、触摸和键盘操作不受影响。编辑框内的开头 / 末尾跳转保持原逻辑。

### 悬浮编辑窗关闭与保存

- **实时同步窗口**没有单独的保存步骤：已写回原框或未修改的内容，即使原框关闭、切换后窗口锁定，关闭或刷新也不再提示未保存。关闭前会尝试写回尚未结束的输入法组字；仅尚未同步到原框的本地修改需要确认。
- **写回原框不等于原插件已保存**：世界书、CSS、插件配置等仍需按原界面的保存方式处理；关闭窗口不撤销已同步的修改。
- **独立草稿规则不变**：角色字段自动保存，预设条目草稿关闭时自动保存；失败、结果未确认或发生冲突时保留草稿，并在丢弃前确认。整份命名预设仍需在酒馆保存，未保存草稿不会跨刷新恢复。

## 插件接口

QuickBar 提供悬浮编辑按钮接入，以及 `window.STQuickBar.registerExternalButton()` 运行时快捷入口注册，详见 [integration.md](integration.md)。

运行时入口由来源脚本选择工具栏或悬浮面板，不参与 QuickBar 的扫描、按钮管理或按钮选择器，也不修改已保存布局；来源可用句柄 `isActive()` 判断宿主与目标区域是否启用，管理自身备用入口。接口为兼容既有来源脚本保留；新接入优先使用标准魔法棒按钮，再由用户扫描管理。
